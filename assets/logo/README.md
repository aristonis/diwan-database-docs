# Logo

| File | Use |
|---|---|
| `diwan-database.svg` | Main logo, colour, no background |
| `diwan-database-tile.svg` | The same on its dark tile, for app icons and avatars |
| `diwan-database-small.svg` | 16–64 px: favicon, avatars |
| `diwan-database-line-black.svg` / `-line-white.svg` | One colour, for light or dark backgrounds |
| `diwan.svg` | The Diwan umbrella mark |
| `lockup-horizontal-light.svg` / `-dark.svg` | Mark with the name |

Keep clear space around the mark of about a fifth of its width. Don't stretch, recolour or add effects.
