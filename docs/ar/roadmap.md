# خارطة الطريق

ما يأتي بعد 0.1.0. قد يتغير الترتيب والنطاق، وأي بند يطلبه مستخدم يتقدم في القائمة. لطلب بند، افتح
[طلب ميزة](https://github.com/aristonis/diwan-database/issues/new/choose).

| الحالة | المعنى |
|---|---|
| Next (التالي) | مخطط للإصدارات القادمة. |
| Planned (مخطط) | مطلوب، ولم يُجدول بعد. |

## الإصدار والأدوات

| الميزة | الوصف | الحالة |
|---|---|---|
| واجهة سطر أوامر للترحيلات (Migration CLI) | `migrate` و `rollback` و `reset` و `refresh` و `fresh` و `status` و `make:migration` من قوالب. | Next |
| اكتشاف الترحيلات وقت البناء | معالج تعليقات توضيحية (annotation processor) يجد فئات الترحيل وقت الترجمة ويثبّت أسماءها قبل أن يعيد R8 تسمية أي شيء. | Next |
| تعليقات توضيحية للعلاقات والنطاقات | عرّف العلاقات والنطاقات (scopes) بتعليقات توضيحية؛ والمعالج نفسه يولّد التسجيل، دون انعكاس (reflection) وقت التشغيل. | Next |
| وصفة ربط مجمّع الاتصالات (pool) | إعداد موثّق لـ HikariCP و Agroal مع مدير قواعد البيانات. | Planned |
| طبقات Java 21 | مطابقة الأنماط (pattern matching) في القواعد النحوية (grammars) عبر JAR متعدد الإصدارات، مع بقاء دعم Java 17. | Planned |

## النماذج

| الميزة | الوصف | الحالة |
|---|---|---|
| المصانع (Factories) | مصانع نماذج بحالات وعلاقات، لبيانات الاختبار. | Next |
| تحويلات المجموعات والتشفير | `AsCollection` و `AsArrayObject` وتحويلات مشفّرة (casts) بمزوّد مفاتيح. | Planned |
| تحويلات التجزئة والثنائية | تحويل مجزّأ (hashed) لكلمات المرور، وتحويلات UUID و ULID ثنائية. | Planned |
| مساعدات مجموعة النماذج | `toQuery` و `only` و `except` و `diff` و `intersect` و `unique` على مجموعات النماذج. | Planned |
| التقليم (Pruning) | نماذج قابلة للتقليم فردياً وجماعياً للتنظيف المجدول. | Planned |
| التحميل المسبق التلقائي | تحميل العلاقات على دفعات، لتجنّب استعلامات N+1 دون الحارس الصارم. | Planned |
| مساعدات استعلام العلاقات | `withWhereHas` و `whereBelongsTo` و `whereAttachedTo`. | Planned |
| متعدد إلى متعدد عبر وسيط | علاقات عبر وسيط (through) تمر بجدول ربط (pivot). | Planned |
| إضافات العلاقات والنماذج | دوال Laravel الأصغر مثل `incrementEach` و `valueOrFail` و `restoreOrCreate` و `withAttributes`. | Planned |
