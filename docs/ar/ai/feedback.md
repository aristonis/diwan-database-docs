# الملاحظات

الوثائق والمهارات تُكتب يدويًا وتُراجَع على المصدر، ومع ذلك قد تخطئ أو تغمض. ملاحظات المستخدمين ووكلائهم هي ما يصلحها.

## إلى أين ترسلها

| بخصوص | أين |
|---|---|
| هذا الموقع: مثال خاطئ، صفحة ناقصة، جملة غامضة، ترجمة سيئة | GitHub Discussions أو Issues في `aristonis/diwan-database-docs` |
| مهارة أو قواعد `AGENTS.md`: قاعدة أعطت الـ agent كودًا خاطئًا، أو مزلق ناقص | GitHub Issues في `aristonis/diwan-database` |
| خلل في المكتبة | [الإبلاغ عن مشكلة](report-issue.md) |
| مشكلة أمنية في المكتبة أو مهارة أو هذا الموقع | بسرية على https://github.com/aristonis/diwan-database/security/advisories/new. لا تفتح issue عامة أبدًا. |

تُفتح المستودعات للعامة مع الإصدار الأول. إلى ذلك الحين أرسل ملاحظاتك إلى المشرفين مباشرة.

## ما الذي يفيد

- اسم الصفحة أو المهارة، والسطر أو العنوان.
- ما توقعته وما حصل. وللـ agent: المهمة التي أعطيتها له والكود الذي كتبه.
- إصدار Diwan والمنصة (إصدار Java أو مستوى Android API).
- الإصلاح إن وجدته. أفضل بلاغ هو مثال كود خاطئ مع الصحيح بجانبه.
- في الترجمة: الجملة العربية وصياغة أفضل.

## ما الذي تتركه

الأسرار وسلاسل الاتصال التي فيها كلمات مرور وبيانات من قاعدة بياناتك. استبدل بها قيمًا بديلة.

لا تتغير قاعدة أو مهارة إلا إذا أيّدها المصدر أو الدليل. والملاحظة التي تشير إلى السطر في المصدر تُعالَج أسرع.
