# وكلاء الذكاء الاصطناعي

تشحن Diwan ملفات يقرؤها الـ agent (وكيل برمجي، مثل Claude Code وCodex وCursor) ليكتب كود Diwan صحيحًا في مشروعك. توجد في مجلد `ai/` داخل مستودع الكود بجانب المصدر، فتطابق الإصدار الذي تستعمله.

## ما في `ai/`

| الملف | ما هو |
|---|---|
| `ai/README.md` | ما هذا المجلد وكيف يُحمَّل. |
| `ai/AGENTS.md` | ملف القواعد: ما هي Diwan، نقطة الدخول لكل قاعدة بيانات، قواعد "افعل دائمًا" و"لا تفعل أبدًا"، وأين الوثائق. انظر [ملف قواعد الـ agent](agent.md). |
| `ai/skills/<name>/SKILL.md` | مهارة (skill) لكل مهمة بصيغة Agent Skills. انظر [المهارات](skills.md). |

القواعد مع أسبابها في صفحة [القواعد](rules.md). للإبلاغ عن خلل انظر [الإبلاغ عن مشكلة](report-issue.md). وللتعليق على الوثائق أو مهارة انظر [الملاحظات](feedback.md).

## وجّه الـ agent إليها

1. الصق الكتلة من [ملف قواعد الـ agent](agent.md) في ملف `AGENTS.md` أو `CLAUDE.md` الخاص بمشروعك.
2. انسخ المهارات التي تحتاجها إلى مجلد المهارات عند الـ agent:

```bash
cp -r ai/skills/* .claude/skills/
```

3. اطلب العمل بكلام عادي. يحمّل الـ agent المهارة حين يطابق وصفها المهمة.

تبقى الأدلة في هذا الموقع هي المرجع. إذا اختلفت مهارة مع دليل فاتبع الدليل وأرسل ملاحظة.

## llms.txt

ملف `llms.txt` لهذا الموقع (فهرس نصي بسيط للصفحات للأدوات التي تقرأ الويب) مخطّط له ولم يُنشر بعد. إلى أن يصدر، وجّه الـ agent إلى صفحات [الأدلة](../getting-started.md) أو إلى مجلد `ai/`.
