# دليل الترقية

`0.1.0` هو الإصدار الأول، فلا شيء تُرقّي منه. ابدأ من [البدء](getting-started.md).

## قواعد بيانات أنشأها إصدار تجريبي

إذا شغّلت Diwan من snapshot أو من بناء محلي قبل `0.1.0`، فقد يفتقر جدول الـ migrations عندك إلى عمود `checksum` الذي تستعمله `0.1.0` لكشف
الـ migrations المعدَّلة. لا تعدّل Diwan الجدول أثناء التشغيل أبدًا. أول استدعاء للـ migrator يحتاج العمود يفشل برسالة تسمّي العبارة الواحدة
المطلوب تشغيلها. شغّلها مرة واحدة، على SQLite أو PostgreSQL:

```sql
alter table migrations add column checksum varchar(64);
```

استعمل اسم جدولك إن غيّرته. القواعد التي أنشأتها `0.1.0` فيها العمود أصلًا.

## تواريخ SQLite

كتبت البناءات التجريبية بعض تواريخ SQLite بصيغة `2026-01-02T03:04` أو مع إزاحة محلية. تكتب `0.1.0` الصيغة `yyyy-MM-dd HH:mm:ss`، مع كسر
عشري فقط حين يوجد، وتكتب `Instant` بتوقيت UTC مع `+00:00`. النص القديم لا يُرتَّب ولا يُقارن مع النص الجديد. أعد كتابة القيم القديمة قبل مقارنتها.

## ما أُزيل في 0.1.0

أدوات المال (`Blueprint.money` و`Money` و`MoneyAmount`) أُزيلت. استعمل `decimal` أو عمودًا صحيحًا بوحدات صغرى. عمود مال أنشأه إصدار تجريبي
يبقى قيده المولَّد كقيد عادي.
