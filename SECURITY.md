# Security policy

This repository holds the documentation site for Diwan Database.

## Reporting a vulnerability

Report a security problem privately. Do not open a public issue, a public discussion or a pull
request for it.

- A problem in the library itself: use GitHub private vulnerability reporting at
  <https://github.com/aristonis/diwan-database/security/advisories/new>.
- A problem in this site (for example a script injection in a page or an unsafe example that
  teaches a vulnerable pattern): use the same channel and name the page.

Include the Diwan version and module, the database and its version, what an attacker can do, the
smallest code or page that shows it, and the full error with its cause chain if there is one.
Leave out real secrets, connection strings with passwords and personal data.

## What to expect

A maintainer reads each report and replies in the advisory thread. We confirm the problem, work on
a fix with you in private, and publish an advisory with the fix. We credit the reporter unless you
ask us not to. We do not promise a date.
